How to pull the data — step by step
1
Quit the WHOOP app on your phone first. A band only talks to one device at a time, so if the official app is connected, we can't be.
2
Tap Connect WHOOP above and pick your band. Live heart rate should start showing on the other tabs straight away.
3
Tap Start capture (it turns green). This records every raw message the band sends, so nothing is lost.
4
Tap get_hello, then data_range, then Realtime HR (it turns on) — that asks the band to stream its live sensor data.
5
Watch fd4b frames count up for about 20 seconds. The more it climbs, the more data we get.
6
Tap Dump & copy. The captured data is copied to your clipboard (and shown in the box). Paste it to Claude — that's the bit we decode to teach the app real recovery / strain / sleep.
7
When done, send command 3 data 00 to stop the stream. Repeat over a few days (including after sleep) so we capture a full picture.
Collecting & comparing — recommendations

• Always wear the band while capturing — off the wrist there's no pulse, so the data is just noise.

• This app and the official WHOOP app take turns on Bluetooth — a band talks to one device at a time. Quit the WHOOP app before connecting here, and reopen it after.

• Keep using the WHOOP app normally otherwise. It keeps the band recording everything (including sleep) and its numbers are the answer key we calibrate against.

A
Live capture — wear it, quit the WHOOP app, connect, turn Realtime HR on, capture ~20 s, then Dump & copy.
B
Full day / sleep — live normally with the WHOOP app (wear it overnight). Later, quit the app, connect here, tap data_range, capture, then Dump & copy.
C
With every dump, note the WHOOP app's numbers for that same day — Recovery %, Day Strain, Sleep %, HRV (ms), Resting HR — and send them alongside the dump. That pairing is what calibrates the screens above to match WHOOP.
Commands
Historical sync — for Recovery / Sleep / Strain

Live heart rate is only “now”. Your Recovery, Sleep and full-day Strain are built from the band's stored history — recorded while you wear it, especially overnight. This pulls that buffered history off the band so it can be decoded into your real scores.

Wear it (including a night), then tap Sync full history. It streams each batch of records and acknowledges it so the band releases the next, looping until HISTORY_COMPLETE. Watch HISTORICAL climb in the fd4b counter below. ⚠️ This is DESTRUCTIVE: acknowledging frees the records on the band, so anything the official WHOOP app hasn't already synced is permanently lost from WHOOP. Let the WHOOP app finish syncing FIRST. Leave it until it logs SYNC COMPLETE, then Save file / Send to laptop.

Quick sync (read-only) — streams just the first window without acknowledging anything, so absolutely nothing changes on the band. Useful for a fast sample capture. Tap to start, tap again to stop, then Save file.

Band buffer tools

Check the sync cursor — reads the band without changing anything and shows its sync cursor (the oldest point not yet marked as synced). ⚠️ This is only a marker, not what's physically stored: the band keeps days of records in its flash chip, and Sync full history reads them from the very start regardless of this cursor — so data that looks “gone” here can usually still be pulled.

Experiment: can we read without deleting? “Sync full history” normally frees records as it reads (destructive). These options try a different acknowledgement to see if the band will hand over the history without freeing it. ⚠️ Only pick an experiment option on THROWAWAY data you don't mind losing — e.g. an hour of daytime wear with the WHOOP app force-closed — because if it fails it still frees that data. Then run Sync full history above and read the “oldest BEFORE / AFTER” line in the log — if the oldest time did not move, we read it non-destructively. 🎉

Leave on Normal for real pulls. Try A first, then B, then C — each on a fresh throwaway hour. Save the file after every run.
Read-pointer experiment (cmd 33)

The band remembers how far it has been read with a little counter (a “read pointer”). The big idea: move that pointer ourselves so we can (a) walk through the whole history without the destructive ack, or (b) rewind it after a pull so the WHOOP app can still read the night. This is read-only and safe — it just moves a counter, it doesn't delete anything.

How to test the rewind: ① tap Read pointer (note the oldest time). ② run a normal Sync full history (the oldest jumps to “now”). ③ tap Read pointer again, then type the old pointer value back in and tap Set pointer. If the oldest time jumps backward, we can rewind — and WHOOP can re-read. 🎉

If Set pointer says “No change”, switch the encoding (16-bit LE / 32-bit BE) and tap again. Save the file after the run so it can be checked.

Seek to a night — pick a date & time and tap Seek. cmd 33 is the band's “Force Read Pointer” (it takes a flash page number); the app converts your time to a page, jumps there, checks where it actually landed, and corrects itself a couple of times. When it says “within 10 min”, tap Sync full history and it pulls from that point instead of walking days from the start. Aim a couple of hours before bedtime to catch the whole night. (The encoding dropdown is only for the manual Set pointer above — Seek always uses the page format.)

Uses the encoding selected above. If it says “the read head did NOT move”, switch the encoding and try again. Start capture first and save the file afterward.

Try high-freq-sync reset (cmd 96) — the official WHOOP 5.0 app sends a handshake (“enter high-frequency sync”) before pulling history, which we’ve never sent. This taps it and checks whether it rewinds the read back to the oldest record — the reset we’re after. Safe (it’s a normal sync command). Start capture first, then save the file.

⭐ Reboot to rewind — from the decompiled WHOOP command list we found the band’s own reboot commands. A reboot rewinds the read pointer to the oldest record (this is what happened by accident on June 21). Power-cycle (cmd 32) is the strongest candidate; soft reboot (cmd 29) is the gentler one. Each reboots the band (~20–40s) — the same as the official app’s “device reboot”, so it’s safe. Force-close the WHOOP app first, send the reboot, wait, reconnect, then immediately tap Sync full history and watch whether it starts from days ago.
